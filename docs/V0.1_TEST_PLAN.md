# V0.1 — manual smoke test

1. Import `project.godot` in Godot 4.7 (official development version); run F5.
2. Choose Verddro. Verify Bosque Esmeralda, green dragon placeholder, movement (WASD + arrows), camera follow.
3. Walk into a tree / stall / guard: movement should be blocked. Walk to map edge: cannot leave map.
4. Approach crystal, tree, artisan and soldier; press E. Bottom dialogue should change. Soldier does not trigger battle yet.
5. Press ESC: menu returns. Choose Tavorko. Verify distinct Vila das Trocas map, archer placeholder and dialogues.
6. Observe Godot Debugger for errors. If an error occurs, provide the first error message and its script/line.

Known scope: illustrative placeholder visuals, no final art, no touch controls, no save system or multiplayer in V0.1.
